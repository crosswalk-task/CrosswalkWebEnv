# crosswalk-web-env

[![npm version](https://img.shields.io/npm/v/crosswalk-web-env.svg)](https://www.npmjs.com/package/crosswalk-web-env)

An npm package for the web version of CrosswalkEnv.

## Requirements

- React 19.2.8+
- React DOM 19.2.8+
- styled-components 6.5.2+

## Installation

```bash
npm install crosswalk-web-env
```
